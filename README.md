# RepSearch public pages

The landing page and legal pages for RepSearch, served by GitHub Pages.

This repository is generated. The text is edited in the app repository
(`docs/privacy-policy.md`, `docs/terms-of-use.md`, `docs/health-disclaimer.md`,
`docs/account-deletion.md`, `marketing/landing/index.html`) and copied here by
`node marketing/publish-site.cjs <path to a clone of this repository>`. A change
made directly here is overwritten by the next publish.
